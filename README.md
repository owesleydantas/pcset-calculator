# 🖥 Calculadora PCS

> Biblioteca para análise de conjuntos de classes de altura (Pitch Class Set) em JavaScript/TypeScript, executando diretamente no navegador.

## 🔗 Acesse a calculadora online: [Clique aqui](https://owesleydantas.github.io/pcset-calculator/)

## 🔧 Funcionalidades
- Normalização de PCS
- Forma normal  (Normal Order)
- Forma prima (Prime Form)
- Vetor Classe Intervalar (ICV)
- Transposição (Tn)
- Inversão (TnI)
